## 一、产品定位

**一句话定位**：输入角色和故事，3 分钟得到第一条漫剧草稿；想精修，随时进入专业工作台。

**目标用户**：短视频/短剧创作者、小说/漫画爱好者、AI 绘画/视频尝鲜者、自媒体/网文作者。

**核心特性**：
- 模型中立、用户自带 API Key
- 极速模式优先、专业模式后置
- 角色一致性是核心护城河
- 镜头语言引导降低提示词门槛
