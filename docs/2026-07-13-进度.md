## 本次完成的功能

### ✅ P1-2 角色四视图生成

**功能说明**：为角色生成正面、四分之三侧面、侧面、背面四个角度的参考图，确保角色在不同镜头中保持一致的外观。

**实现内容**：

后端：
- `characters.service.ts` - 新增 `generateViewImages()` 方法
- `characters.controller.ts` - 新增 `POST /:characterId/generate-views` 和 `DELETE /:characterId/views` 端点
- 修复 API Key 解密逻辑，使用独立的 CryptoService

前端：
- `CharacterDetailPanel` 组件的「四视图」Tab
- 2x2 网格展示四个角度的图片
- 支持一键生成和清除操作

---

### ✅ P1-3 角色变体系统

**功能说明**：为角色生成不同表情、服装和场景的变体图片，用于分镜中展示角色的情绪变化、服装更换或场景转换。

**实现内容**：

后端：
- `characters.service.ts` - 新增 `generateVariants()` 和 `deleteVariant()` 方法
- `characters.controller.ts` - 新增变体生成和删除 API
- 预定义 15 种变体类型（6 种表情 + 5 种服装 + 4 种场景）

前端：
- `CharacterDetailPanel` 组件的「变体」Tab
- 按类别分组展示可生成的变体类型
- 已生成变体的网格展示，支持删除操作
- 实时更新变体数量统计

**支持的变体类型**：

| 类别 | 变体类型 |
|------|---------|
| 表情 | 开心、悲伤、愤怒、惊讶、害羞、自信 |
| 服装 | 休闲装、正装、校服、运动装、奇幻装 |
| 场景 | 室内、户外、夜晚、黄昏 |

---

### ✅ P1-4 角色锁定强度

**功能说明**：控制角色在不同分镜中的一致性程度，提供三档选择：

- **宽松**：允许较大变化，适合创意探索阶段
- **中等**：保持基本特征（发型、服装风格），允许表情和姿态变化（默认）
- **严格**：高度一致，适合需要强连贯性的连续剧情

**实现内容**：

后端：
- `characters.service.ts` - 支持 `lockLevel` 字段的更新
- `characters.controller.ts` - 更新角色 API 支持 lockLevel 参数

前端：
- `CharacterDetailPanel` 组件的「锁定强度」Tab
- 三档选择卡片，带图标和说明
- 当前选中状态高亮显示
- 创建角色时可选择初始锁定强度

## API 端点汇总

### 角色四视图

| 方法 | 端点 | 说明 |
|------|------|------|
| `POST` | `/projects/:projectId/characters/:characterId/generate-views` | 生成角色四视图 |
| `DELETE` | `/projects/:projectId/characters/:characterId/views` | 清除角色四视图 |

### 角色变体

| 方法 | 端点 | 说明 |
|------|------|------|
| `POST` | `/projects/:projectId/characters/:characterId/variants/:variantType` | 生成角色变体 |
| `DELETE` | `/projects/:projectId/characters/:characterId/variants/:variantId` | 删除角色变体 |
| `GET` | `/projects/:projectId/characters/variant-types` | 获取变体类型列表 |
